# Security Policy

## Reporting a vulnerability

Please report security issues privately via GitHub's **Security → Advisories**
feature on this repository. Do not open a public issue with exploit details.

Include the app version, Android version, device model, and a minimal
reproduction. Never include real API keys or tokens.

## Scope

- the Adia launcher and bundled skills
- the offline toolbox/toolchain provisioning
- the local opencode server pairing/auth flow

Third-party components (opencode, Termux packages, proot, JDK, Android SDK)
should be reported to their respective upstream projects when the issue is in
those components.
